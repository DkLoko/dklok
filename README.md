# Mod Hub

A simple, dark-themed public mod browser with drag-and-drop support.

## Features

- Clean dark red design
- Drag & drop to add mods
- Search and category filters
- Files are stored in the browser
- One-click "Clear All Mods" button
- Rain + mist atmosphere

## How to use

1. Open the page
2. Drag your mod files into the drop zone (or click to select)
3. Your mods will appear as cards
4. Click **Download** on any card to get the file

## For visitors

Just open the page and download whatever mods are listed.

## Notes

- Maximum recommended file size is about 4 MB per mod (browser storage limit)
- Use the **Clear All Mods** button if you want to reset everything
- This is a client-side tool — no accounts or servers required
